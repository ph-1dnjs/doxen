# 섹션 검색 사용 가이드

각 표 위에 검색창이 자동으로 표시됩니다. `:::search` 영역으로 감싸면 검색창 이름을 지정할 수 있습니다. 검색어를 지우면 모든 행이 다시 표시됩니다.

## 1. 문서 준비

:::search 문서 준비 검색
| 작업 | 사용 방법 | 확인할 내용 |
| --- | --- | --- |
| 문서 추가 | Markdown 파일 생성 | 제목 작성 |
| 문서 연결 | tabs에 전용 폴더 지정 | 탐색 목록 확인 |
| 문서 정렬 | 파일 이름에 번호 추가 | 목록 순서 확인 |
| 링크 추가 | 상대 경로 사용 | 이동 대상 확인 |
| 이미지 추가 | 지원 형식의 파일 연결 | 이미지 표시 확인 |
| 제목 추가 | Markdown 제목 문법 사용 | 목차 표시 확인 |
:::

## 2. 검색 실행

:::search 검색 실행 방법
| 작업 | 사용 방법 | 확인할 내용 |
| --- | --- | --- |
| 전체 검색 | 상단 검색 버튼 클릭 | 모든 탭에서 검색 |
| 표 검색 | 표 위 검색창 사용 | 해당 표의 행만 검색 |
| 독립 검색 | 다른 표의 검색창 사용 | 기존 표의 필터 유지 |
| 결과 표시 | 검색어가 포함된 행 표시 | 나머지 행 숨김 |
| 검색 초기화 | 입력한 검색어 삭제 | 모든 행 복원 |
:::

## 3. 검색 영역 배치

제목은 검색 영역 밖에 둡니다. 표가 없는 설명에는 검색창이 표시되지 않습니다. 검색 영역은 중첩하지 않습니다.

## 4. 미리보기 확인

:::search 미리보기 확인 항목
| 작업 | 사용 방법 | 확인할 내용 |
| --- | --- | --- |
| 로컬 실행 | `docs dev` | 브라우저에서 열기 |
| 변경 확인 | Markdown 수정 후 저장 | 자동 갱신 확인 |
| 빌드 확인 | `docs build` | 출력 폴더 확인 |
:::
