# [분기와 엣지 케이스] 회원가입

> **문서 정보 범위:** 번호별 단계와 선택형 검색 영역을 보여주는 예제입니다. 아래 내용은 화면 구성용이며 실제 서비스 정책이 아닙니다.

---

## 1. 사업자 정보 단계

:::search 사업자 정보 단계 검색
| 상황 | 현재 동작 | 다음 행동 |
| --- | --- | --- |
| 사업자등록번호 없이 조회 | 필수 입력 안내 | 번호 입력 후 재조회 |
| 조회 후 사업자번호 변경 | 기존 검증 상태 초기화 | 새 번호로 다시 조회 |
| 가입 가능한 사업자 | 가입 가능 상태 표시 | 나머지 사업자 정보 입력 |
| 기존 가입 사업자 | 기존 계정 안내 | 로그인 화면으로 이동 |
| 가입 대기 사업자 | 대기 상태 안내 | 관리자 문의 |
| 사업자 정보 불일치 | 입력 확인 안내 | 사업자 정보 수정 |
| 업태 변경 | 종목 선택 초기화 | 새 업태의 종목 선택 |
| 도매 및 소매업 | 추가 정보 입력 표시 | 해당 정보 입력 |
| 정기휴무일 없음 선택 | 다른 요일 선택 해제 | 다음 단계로 이동 |
:::

## 2. 회원·담당자 정보 단계

:::search 회원·담당자 정보 단계 검색
| 상황 | 현재 동작 | 다음 행동 |
| --- | --- | --- |
| 아이디 미입력 | 필수 입력 안내 | 아이디 입력 |
| 비밀번호 확인 불일치 | 불일치 안내 | 비밀번호 재입력 |
| 휴대폰 인증 요청 | 인증번호 입력 표시 | 문자 수신 후 번호 입력 |
| 인증번호 만료 | 만료 안내 | 인증번호 재요청 |
| 필수 약관 미동의 | 다음 단계 진행 제한 | 약관 확인 후 동의 |
:::

## 3. 이탈·완료 화면

입력 도중 화면을 나가는 경우와 완료 후 이동 경로를 설명합니다. 짧은 설명만 있는 섹션에는 검색창을 추가하지 않습니다.

## 4. 공통 오류 처리

:::search 공통 오류 검색
| 상황 | 현재 동작 | 다음 행동 |
| --- | --- | --- |
| 네트워크 연결 실패 | 재시도 안내 | 연결 확인 후 재시도 |
| 서버 오류 | 처리 실패 안내 | 잠시 후 다시 시도 |
| 인증 만료 | 재인증 안내 | 다시 인증 |
:::
