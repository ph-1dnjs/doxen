# 문서 작성 가이드

## 읽기 쉬운 구조

첫 줄에는 문서 제목을, 각 주제에는 2단계 제목을 사용합니다. 제목은 자동으로 목차와 검색 위치가 됩니다.

## 표 검색

표를 작성하면 검색창이 자동으로 추가됩니다. 입력한 문자열이 있는 행만 표시하고, 검색어를 지우면 모든 행을 복원합니다. 검색창 이름을 지정하려면 표를 `:::search`와 `:::`로 감싸세요.

```markdown
## 1. 문서 작성

:::search 작성 방법 검색

| 작업 | 설명 |
| --- | --- |
| 제목 작성 | Markdown 제목 문법 사용 |
| 링크 추가 | 상대 경로 사용 |
:::
```

## 링크와 첨부 파일

Markdown 상대 링크는 사이트 문서로 연결됩니다. 문서 폴더 안의 PNG, JPEG, GIF, WebP, AVIF, ICO, PDF 첨부 파일은 빌드에 포함됩니다.

실행 가능한 HTML과 MDX는 지원하지 않습니다. Markdown은 안전한 HTML로 변환됩니다.
