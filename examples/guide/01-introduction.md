# 팀의 지식을 한곳에

Safibook은 저장소에 있는 Markdown을 팀의 문서 사이트로 연결합니다. 익숙한 Git 흐름은 그대로, 필요한 지식은 더 빠르게 찾으세요.

> 설정 파일 하나로 시작하세요. 사이트 화면과 검색 기능은 Safibook이 준비합니다.

## 시작하기

기존 프로젝트에 개발 의존성으로 설치하고 문서 폴더를 연결합니다.

```bash
npm install -D @unana_dev/doxen
npx docs init
npx docs dev
```

## 문서를 연결하는 방법

정책, 프론트엔드, 백엔드처럼 팀에 맞는 탭을 만들 수 있습니다. 탭 이름과 경로는 설정에서 자유롭게 바꿉니다.

| 기능 | 사용 방법 |
| --- | --- |
| 문서 전환 | 상단 탭과 왼쪽 문서 목록 |
| 전체 문서 검색 | 검색 버튼 또는 ⌘ / Ctrl K |
| 문서 내 위치 찾기 | 본문 위 검색창과 이전·다음 버튼 |
| 섹션 검색 | 필요한 영역에 `:::search` 표시 |

## Git으로 함께 관리하기

1. 문서 브랜치를 만들고 Markdown을 수정합니다.
2. Pull Request로 변경 내용을 검토합니다.
3. 병합 후 호스팅 서비스에서 `docs build`를 실행합니다.

배포 결과는 `.docs-dist/`에 생성됩니다. 계정 접근 제한은 호스팅 서비스에서 설정하세요.

:::search 팀 용어 빠르게 찾기
## 용어 사전

| 용어 | 설명 |

| 정책서 | 서비스의 운영 원칙과 의사결정 기준 |
| 정산 | 거래 내역을 확인하고 지급 금액을 계산하는 과정 |
| 탭 | 문서 폴더를 묶어 보여주는 탐색 단위 |
| 검색 인덱스 | 제목과 본문을 섹션 단위로 찾기 위한 데이터 |
